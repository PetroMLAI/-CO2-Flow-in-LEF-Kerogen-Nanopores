# -CO2-Flow-in-LEF-Kerogen-Nanopores
Applied Knudsen-corrected pore network modeling and machine learning to FIB-SEM imaging of Eagle Ford shale, isolating the standalone effect of nanopore physics from network-topology effects on permeability, and showing CO2-EOR recovery couldn't be predicted from bulk statistics alone, even when porosity and average connectivity were held constant.
